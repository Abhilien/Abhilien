# Waypoint: an ADHD executive-function layer. Research & product concept

This folder holds the full research and product concept for an ADHD-focused mobile app.
The working name is **Waypoint**. It is a placeholder, and trademark clearance is still needed (see Part 4, §13).

**Read in order:**

1. [`01-research.md`](01-research.md): Executive summary, research findings, ADHD problem map
2. [`02-landscape.md`](02-landscape.md): Existing product landscape, community research, unmet needs
3. [`03-product.md`](03-product.md): Thesis, principles, the full feature set with a critique of every original idea, the features we missed, and detailed specifications
4. [`04-experience.md`](04-experience.md): AI architecture, UX architecture, home screen, personality, notifications, conversations, user journeys, first month
5. [`05-business-and-build.md`](05-business-and-build.md): Prioritisation (MVP to Future), monetisation, market, privacy & safety, accessibility, technical architecture, differentiation, roadmap, risks, open questions, and the final answer
6. [`07-screens-and-build-specs.md`](07-screens-and-build-specs.md): Example screens, data model, cue engine, parser contract and test cases, leave-engine maths, MVP backlog with acceptance criteria, analytics taxonomy, discovery research kit
7. [`06-references.md`](06-references.md): All sources

## Evidence labelling used throughout

| Tag | Meaning |
|---|---|
| **[E]** | **Evidence.** Supported by peer-reviewed research, meta-analyses, clinical bodies, or primary product documentation. Cited. |
| **[I]** | **Inference.** A reasonable conclusion drawn from evidence, but not directly tested in the stated context. |
| **[H]** | **Product hypothesis.** A bet that needs validation with users. |
| **[R]** | **Design recommendation.** What we should do, given the above. |
| **[Q]** | **Qualitative signal.** Community posts, app reviews, practitioner opinion. Useful for product work, but not scientific evidence. |

Citations look like `[n]` and point to `06-references.md`.
Competitor prices were checked in September 2026. They change often, so verify them before you rely on them.
